Today we will study database normalization. Normalization is the process of organizing data in tables to reduce redundancy. First normal form means every column has atomic values and there are no repeating groups. Second normal form removes partial dependency, where a non key column depends on only a part of a composite key. Third normal form removes transitive dependency, where a non key column depends on another non key column. By the way, did you all watch the cricket match yesterday? Okay, coming back, an example: a student table with student id, course id, student name and course name has redundancy, so we split it into a student table and a course table. This makes updates, inserts and deletes safe and avoids anomalies. Boyce Codd normal form is a stronger version of third normal form where every determinant must be a candidate key.
